# Project Images

This directory contains diagrams and other visual documentation for the Raspberry Pi 5 OpenWrt router project.

## Network Architecture

[`architecture-diagram.png`](architecture-diagram.png) shows the deployed network architecture, including the ISP connection, Raspberry Pi 5 OpenWrt router, managed switch, VLAN-segmented networks, Wi-Fi 6 access point, management/recovery network, and WireGuard remote-access path.
